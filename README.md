# MGZ
O MGZ é uma solução interativa voltada para a digitalização e agilidade no processo de atendimento e pedidos.

#Dependências 
- Docker
- Docker compose

## To run

```
- $ git clone https://github.com/marcosolenka/MGZ.git
- $ cd MGZ
- $ docker compose up -d
```

Access [localhost] (http://localhost)

## To stop

```
- $ docker compose down -v
```
